01 Store Management System Large-scale UI
+
Problem

Đội vận hành cần thao tác trên bảng dữ liệu tồn kho hàng trăm nghìn dòng mỗi ngày, nhưng bảng gốc bị treo và giật khi lọc, sắp xếp hoặc cuộn nhanh.

Solution

Viết lại tầng bảng dữ liệu bằng virtualization, chuyển tính toán nặng (lọc, tổng hợp) sang Web Worker, và thiết kế lại luồng fetch theo phân trang kiểu cursor để giảm tải backend.

Tech stack
ReactTypeScriptTanStack Table TanStack VirtualZustandWeb Worker
Architecture

Kiến trúc tách biệt tầng dữ liệu (query cache) khỏi tầng hiển thị (virtualized rows), cho phép mở rộng thêm cột và bộ lọc mà không ảnh hưởng hiệu năng render.

02 Wedding Website Performance / SEO
+
Problem

Cần một trang web thiệp cưới tải nhanh trên mạng di động, đẹp trên mọi kích thước màn hình, và dễ để cô dâu chú rể tự cập nhật nội dung.

Xây dựng bằng Next.js với static generation, tối ưu ảnh tự động, và một hệ thống nội dung đơn giản dạng file để chỉnh sửa không cần biết code.

Architecture

Static site với ISR cho phần RSVP, tối ưu Core Web Vitals để đạt điểm Lighthouse cao trên cả di động.

03 Đền Thờ Dương 1C Content-driven site
+
Problem

Website giới thiệu di tích cần thể hiện được chiều sâu nội dung, hình ảnh và lịch sử, nhưng vẫn phải tải nhanh và thân thiện với công cụ tìm kiếm.

Solution

Thiết kế hệ thống trang nội dung tĩnh, tối ưu SEO on-page (structured data, sitemap, meta), và tối ưu hình ảnh theo định dạng hiện đại để giảm dung lượng tải.

Tech stack
Next.jsTailwind CSSStructured Data
Architecture

Static generation toàn bộ trang nội dung, CDN cho ảnh, và cấu trúc route rõ ràng phục vụ index hoá tốt trên công cụ tìm kiếm.
